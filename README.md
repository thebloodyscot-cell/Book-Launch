# The King's Little Angels — Book Launch Website

A simple two-page static website designed from the supplied invitation.

Files:
- index.html — launch landing page
- location.html — location, parking, accessibility and contact page
- styles.css — styling
- assets/ — invitation artwork and crops

## Free hosting
The easiest free option is GitHub Pages:
1. Create a free GitHub account at github.com.
2. Create a new public repository.
3. Upload all files and the `assets` folder.
4. In Settings → Pages, choose deployment from the `main` branch.
5. GitHub will provide the public website address.

Before publishing, replace the organiser contact placeholder on the home page with the correct email/phone number.

The location page uses Google Maps' embed/search URLs and should be checked after publishing.
